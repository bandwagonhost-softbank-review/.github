## 误区三：软银机房延迟比 CN2 GIA 高

这个误区很有意思，很多人理所当然地认为 CN2 GIA 是顶级线路，软银就一定更差。

如果你比较在意晚高峰稳定性和带宽，DC6 CN2 GIA-E 更适合你；如果你比较在意延迟数字本身（比如做一些对延迟敏感的应用），软银机房会让你看数字更舒服。
